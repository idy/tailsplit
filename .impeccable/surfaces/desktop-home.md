# Desktop home

Visitor mode: Operate. Extend the existing desktop world with a home destination for first connection and everyday routing understanding.

## Direction contract

THESIS: A single connection control leads into a readable split-route diagram. Home is the default destination; Exit Nodes remains the inventory and management surface.

OWN-WORLD: Inherit bundled typography, neutral system surfaces, blue actions, semantic status colors and compact sidebar. Use thin labeled route lines, not traffic charts or decorative imagery. Labels retain ordinary ink; routes never imply measured traffic.

STORY: Turn on once, follow system installation and browser authorization when requested, choose a node, then let the existing flow save and connect. Visible steps explain progress. Cancellation ends the intent. Existing routes and settings remain accessible independently.

FIRST VIEWPORT: Status and a prominent Set up button when no exits are saved and the policy needs one; for configured use the TailSplit snake button replaces it and leads the status block, with the title and description beside it. Four compact setup steps appear when needed. Below, the computer fans out through cubic wires to Direct and every exit referenced by saved routing, following the user-supplied GizMoth serial-map reference. Global mode shows only its selected exit. Endpoint labels come from saved configuration; disconnected paths are dashed. Each destination has trailing upload/download rates from real per-route byte counters; unavailable readings use an em dash. Route activity is conveyed on the wires themselves, without a visible footer summary or explanatory text; links to exits/rules remain available.

FORM: User-pinned routing diagram in the established desktop shell; code-led, no concept tournament or new visual identity. Signature interaction: confirmed connection changes dashed planned paths to solid paths; blocked or lost status never claims a working route. Directional pulses follow real per-route upload/download deltas and stop on idle or unavailable data. Hidden pages pause motion; reduced motion keeps a static activity mark. No invented metrics. Real transfer rates come from successive samples within the same engine session, never from synthetic production values; demonstration fixtures retain the header preview badge.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance. No raster assets are introduced. Verify first setup, connected Split/Global, blocked, error and long labels in both languages and appearances at wide and narrow widths.
